# Looker Studio ダッシュボード設計案

対象: KB2 1年定期購入の業務レポート
データソース: `trustline-project.KB2_1nen` の各ビュー

## 構成（4ページ）

### ページ1: サマリー（経営/管理者向け）

**目的**: 当月の状況をひと目で把握。

| ウィジェット | データソース | 内容 |
|---|---|---|
| スコアカード × 4 | `mart_op_receive_rate_kb2_1year` | 当月_成約数(SUM), 当月_受取数(SUM), 当月_受取率(AVG), 前月_受取率(AVG) |
| 比較指標 | 同上 | 前月比、前々月比をスコアカードに付与 |
| 折れ線グラフ | `subscription_master_KB2_1nen` | 月別成約数の推移（成約日→ MONTH 集計） |
| 折れ線グラフ | `child_orders` | 月別発送数の推移（発送日→ MONTH 集計、対応状況=5） |

### ページ2: OP別パフォーマンス（業務レポートの本体）

**目的**: 担当者ごとの成約/受取を3ヶ月並べて比較。

| ウィジェット | データソース | 内容 |
|---|---|---|
| 表 | `mart_op_receive_rate_kb2_1year` | 全カラムをそのまま表示。OP名で並べ替え可 |
| 棒グラフ（縦） | 同上 | 当月_成約数 by OP名（降順） |
| 棒グラフ（縦） | 同上 | 当月_受取率 by OP名（降順） |
| バブルチャート | 同上 | X=当月_成約数, Y=当月_受取率, サイズ=当月_受取数。OPごとの位置づけ可視化 |
| フィルタ | — | OP名（複数選択） |

### ページ3: 継続率分析

**目的**: コホート（成約月）ごとに定期がどこまで続くかを見る。

| ウィジェット | データソース | 内容 |
|---|---|---|
| ピボットテーブル | `KB2_1年継続率` | 行: first_purchase_month / 列: 1〜16回目 / 値: rate_N（条件付き書式でヒートマップ化） |
| 折れ線グラフ | 同上 | X軸: 1〜16回, Y軸: rate, 線色: first_purchase_month。月別ステップ間継続率の重ね合わせ |
| 折れ線グラフ | 同上（計算フィールド） | 累積継続率 = rate_1, rate_1×rate_2, … （Looker Studio 上で計算） |
| フィルタ | — | first_purchase_month の期間 |

### ページ4: 詳細データ（探索用）

**目的**: 個別の成約をドリルダウン。

| ウィジェット | データソース | 内容 |
|---|---|---|
| 表 | `subscription_master_KB2_1nen` | 成約日, マスタID, 企業名, 担当者名, クーポン, source_tab |
| フィルタ | — | 成約日範囲、企業名、担当者名、クーポン |

## 接続手順（Looker Studio）

1. https://lookerstudio.google.com にアクセス
2. 「空のレポート」を作成
3. データ追加 → **BigQuery** コネクタ
4. プロジェクト `trustline-project` → データセット `KB2_1nen` → 各ビューを追加
5. 上記ウィジェットを配置

## 注意点

- **`KB2_1年継続率` の `first_purchase_month` は STRING（YYYY-MM）**。日付フィルタを使いたい場合は、Looker Studio で計算フィールド `PARSE_DATE("%Y-%m", first_purchase_month)` を作成。
- **OP別受取率の「当月」はクエリ実行時点の月**。Looker Studio のキャッシュ更新タイミングに注意（手動 or 12時間ごと）。
- **`child_orders` の発送日は TIMESTAMP**。日次集計するなら `DATE(発送日)` を計算フィールドに。
- **`subscription_master_KB2_1nen` は Google Sheets 由来**。シートの更新がそのまま反映されるが、`master_id` が数値化できない行は除外される（`SAFE_CAST` で NULL になるためフィルタ済み）。
